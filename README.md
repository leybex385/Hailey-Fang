# NOT JUST A LABEL | Hailey Fang Portfolio

This is a premium fashion portfolio website for Hailey Fang, U.S. Regional Director of NOT JUST A LABEL.

## Features
- **Modern Design**: Clean, elegant aesthetics with a focus on high-end fashion.
- **Responsive**: Fully optimized for various screen sizes.
- **Interactive**: Smooth transitions, modals for detailed views, and an engaging user experience.

## Getting Started

### Local Development
To view the website locally, you can use any static file server. For example:

1. **Using Python**:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.

2. **Using Node.js (npx)**:
   ```bash
   npx serve
   ```
   Then open the provided URL (usually `http://localhost:3000`).

### Deployment to GitHub
To deploy this website to GitHub Pages:

1. Create a new repository on GitHub.
2. Push this folder to the `main` branch.
3. Go to **Settings > Pages**.
4. Select "Deploy from a branch" and choose the `main` branch and `/ (root)` folder.
5. Save, and your site will be live at `https://<your-username>.github.io/<repo-name>/`.
